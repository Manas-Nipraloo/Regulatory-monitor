About this tool

For sources the automated scraper can't reach (blocked, JS-locked, etc.). Download the PDF yourself, drop it below with its published date, generate a summary, then draft the combined email — same pipeline as the automated sources (Drive upload, AI summary, email draft).

Good to know

Only PDF files are accepted — other formats are ignored on drop.
Uploads sync to the same Drive folder as automated sources.
Summaries are editable before you draft the combined email.
